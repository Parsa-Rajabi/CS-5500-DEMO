# CS 5500 - API Testing Demo Repository

**An interactive educational application for learning API testing concepts**

## 🎯 What Is This?

This repository contains a complete **BC Cancer API Testing Activity** designed for CS 5500 students to learn:

- ✅ **Unit Testing** - Testing individual functions
- ✅ **Integration Testing** - Testing API interactions  
- ✅ **Negative Testing** - Testing error conditions
- ✅ **JavaScript Async Patterns** - Real-world API consumption
- ✅ **Test-Driven Development** - Writing effective tests

## 🚀 Quick Start

1. **Clone the repository**
2. **Navigate to `src/` directory**
3. **Start a web server**: `python3 -m http.server 8000`
4. **Open** `http://localhost:8000` **in your browser**
5. **Open Developer Console** to see test results
6. **Complete the 4 testing tasks** shown on the page

## 📚 What You'll Learn

- How to write unit tests for data transformation functions
- How to test API endpoints and handle responses
- How to implement negative testing scenarios
- Modern JavaScript testing patterns and best practices
